# Ola-Ride-Booking-Analysis
A comprehensive end-to-end data analysis of 20,000+ Ola booking records using MySQL for data engineering and Power BI for interactive business intelligence.
Project Overview Analyzed a dataset of 20,407 Ola bookings for the month of July.

Identified key trends in ride success rates, cancellation reasons, and vehicle performance.

Business Questions Answered
List the core problems your SQL queries solved, such as:

What is the total number of customer cancellations? (2,081).

Which are the top 5 customers by booking volume?.

What is the average rating per vehicle type?.

Key Insights & Findings
Customer Cancellations: The primary reason for the 2,081 cancellations was "Driver is not moving towards pickup location" (610 instances).

Driver Cancellations: Successfully filtered rides where drivers cancelled due to personal or car-related issues.

Revenue: Calculated the total booking value for the 12,652 successful rides.
